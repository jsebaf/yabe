# Inicializar el proyecto Laravel

## Objetivos

- Inicializar una aplicación Laravel funcional a partir del repositorio vacío.
- Utilizar Laravel 13.x y mantener su estructura, convenciones y configuración estándar.
- Dejar el proyecto preparado para el desarrollo posterior del API.
- Configurar el entorno local con SQLite y ejecutar las migraciones iniciales.
- Verificar que la aplicación se puede ejecutar y conectar con la base de datos.

## Notas

- No implementar funcionalidad específica de negocio.
- No añadir dependencias o herramientas adicionales innecesarias.
- No instalar ni utilizar Laravel Boost.
- Usar los valores por defecto recomendados por Laravel siempre que sea posible.
- Todos los cambios necesarios para la inicialización deben quedar registrados en el repositorio.
